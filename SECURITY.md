# Security policy

## Reporting

Report suspected vulnerabilities through GitHub private vulnerability
reporting. Do not open a public issue containing credentials, private paths,
exploit details, or user data.

Include the affected commit SHA, a minimal reproduction, impact, and a safe
way to verify the fix. Remove credentials and personal data from every
attachment and log excerpt.

## Supported code

Security fixes target the current default branch and active integration
branches. Historical commits and local development snapshots are not supported
release surfaces.
